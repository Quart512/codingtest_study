# 두 뭉치에서 순서대로 꺼내기

> [!question] 언제 이 노트를 보나
> 여러 개의 줄(스택/큐/배열)이 있고, **각 줄에서 순서를 바꾸지 않고 앞에서부터** 꺼내서 목표 순열을 만들 수 있는지 묻는 문제.

## 문제의 형태

- 뭉치 A, 뭉치 B가 있다
- 각 뭉치는 **맨 앞부터 순서대로만** 꺼낼 수 있다
- 목표 수열 goal 을 만들 수 있는가?

## 핵심 판단: 그리디로 충분한가

보통 이런 문제는 "지금 A를 쓸까 B를 쓸까" 선택지가 생겨서 완전탐색이 필요해 보인다.
하지만 **원소가 서로 중복되지 않으면 선택의 여지가 없다.**

`goal[k]` 와 같은 값은 A의 맨 앞이거나 B의 맨 앞, 둘 중 하나뿐이다.
둘 다일 수 없으므로 → 매 순간 가능한 수는 딱 하나 → **그리디가 곧 정답**이다.

> [!warning] 뒤집어 말하면
> **중복이 허용되는 순간 그리디는 깨진다.** A와 B의 맨 앞이 둘 다 goal[k] 와 같으면 어느 쪽을 쓰느냐에 따라 뒤가 달라진다. 그때는 DP나 백트래킹으로 가야 한다.
> 문제를 읽을 때 "문자열은 중복되지 않습니다" 같은 조건이 있는지 **반드시** 확인할 것.

## 구현 골격

```python
def solution(a, b, goal):
    i = j = 0
    for x in goal:
        if i < len(a) and a[i] == x:
            i += 1
        elif j < len(b) and b[j] == x:
            j += 1
        else:
            return "No"
    return "Yes"
```

- 뽑지 않고 **어디까지 썼는지만** 기록 → [[투 포인터]]
- 범위 검사 `i < len(a)` 를 값 비교 **앞에** 둔다 → [[IndexError - list index out of range]]
- 전체 O(n), 원본 리스트를 건드리지 않음
