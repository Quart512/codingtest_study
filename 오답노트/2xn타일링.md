# 2 x n 타일링

- 문제: [프로그래머스 12900 - 2 x n 타일링](https://school.programmers.co.kr/learn/courses/30/lessons/12900)
- **코드: [코드/2xn타일링.py](../코드/2xn타일링.py)** ← 통과시킨 코드 원본

> [!info] 이 노트의 역할
> `.py` 에는 실제로 통과시킨 코드만 담백하게 둔다 (테스트 코드의 주석은 예외).
> 설명, 주석, 대안 풀이는 전부 이 노트에 적는다. 코드 파일은 기록, 노트는 회고.

## 무엇을 틀렸나

### 1. 나머지를 구하지 않았다

```python
    answer=b
    return answer
```

문제는 경우의 수를 **1,000,000,007 로 나눈 나머지**로 돌려달라고 했다 (제한사항 마지막 줄).
파이썬 정수는 넘치지 않아서 값 자체는 맞게 나오지만, n=60,000 이면 12,540자리 숫자를 그대로 돌려준다. 나머지가 아니라서 오답이다.

**왜 그렇게 생각했나**

<!-- 이 방식으로 짤 때 머릿속에 있던 전제를 적을 것 -->

**해결**

```python
    answer=b%1000000007
```

→ 반환 형식은 제한사항까지 읽는다. [[카드뭉치]] 에서 `"Yes"` / `"No"` 를 놓친 것과 같은 종류.

## 풀이 이해하기

[[멀리뛰기]] 와 **같은 식**이다. 바닥의 **맨 오른쪽 끝**을 보면 두 가지뿐이다.

| 오른쪽 끝 | 남은 바닥 |
|---|---|
| 세로 타일 1개 | 가로 n−1 |
| 가로 타일 2개를 위아래로 | 가로 n−2 |

그래서 **n 의 방법 수 = (n−1 의 방법 수) + (n−2 의 방법 수).** 멀리 뛰기의 "마지막 점프가 1칸이냐 2칸이냐" 가 여기서는 "마지막 타일이 세로 하나냐 가로 둘이냐" 다.

| n | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 방법 수 | 1 | 2 | 3 | 5 | 8 |

앞 두 칸만 들고 한 칸씩 전진하는 것도 멀리 뛰기와 같다. `a, b = 1, 2` 에서 시작해 `n-2` 바퀴를 돌면 `b` 가 n 의 답이다.

## 이렇게 했으면 어땠을까

### 1. n=1 에서 2가 나온다 — 통과는 했지만

```python
for i in range(n-2):        # n=1 이면 range(-1), 한 번도 안 돈다
    ...
answer=b%1000000007         # 처음 값 b=2 가 그대로 나온다. 정답은 1
```

채점은 통과했다. 채점 입력에 n=1 이 없었던 것으로 보인다 (확인할 방법은 없다). n=2 부터는 답이 맞다 (로컬에서 2 부터 3,000 까지와 60,000 확인).

멀리 뛰기 때의 모양으로 쓰면 n=1 도 맞는다.

```python
def solution(n):
    a,b=1,2
    for i in range(n-1):
        a,b=b,a+b
    return a % 1000000007
```

`a` 가 n 의 답이 되도록 `n-1` 바퀴를 돌면, n=1 일 때는 한 바퀴도 안 돌고 `a=1` 이 나온다.
**`b` 를 답으로 쓰면 `a` 보다 한 칸 앞서 있어서, 가장 작은 입력에서 한 칸 넘친다.**

### 2. 나머지를 더할 때마다 구한다면

n=60,000 에서 마지막에 한 번만 해도 0.04초 (로컬). 멀리 뛰기 노트의 표처럼 n 이 수십만이 되면 더할 때마다 하는 쪽이 빠르다. 이 문제에서는 차이 없다.

## 배운 것

1. 경우의 수를 **오른쪽 끝(마지막 한 걸음)** 으로 나누면, 타일 문제와 계단 문제가 같은 식이 된다
2. 반환 형식은 **제한사항 끝까지** 읽는다. 나머지·문자열·정렬 순서 같은 요구가 거기 있다
3. 반복 횟수가 `n-2` 처럼 입력보다 작으면 **가장 작은 입력**(n=1)을 손으로 넣어 본다
