# 오답노트

**어디서 틀렸는가**를 기록하는 곳. 문제 하나당 노트 하나.

## 원칙

- 코드는 `코드/문제이름.py` 에만 둔다. 이 노트에 풀이 전체를 복붙하지 않는다
- `.py` 에는 **실제로 통과시킨 코드만** 담백하게. 주석 없이 (테스트 코드의 주석은 예외)
- 설명·대안 풀이·회고는 전부 이 노트에
- **틀린 항목마다 [틀린 코드 → 왜 그렇게 생각했나 → 해결]** 세 덩어리를 붙인다. 정답 코드보다 "왜 그렇게 생각했나" 가 자산이다
- 틀린 게 아니라 다르게 풀 수도 있었던 것은 `무엇을 틀렸나` 가 아니라 `이렇게 했으면 어땠을까` 로

## 형식 템플릿

아래를 통째로 복사해서 새 노트를 시작한다.

````markdown

tags: [오답노트, 플랫폼이름, 난이도]

날짜: YYYY-MM-DD
결과: 틀림 → 해결
---
````
