## 풀이의 핵심

### 원형은 두 번 이어 붙이면 일자가 된다

```python
elements=elements*2        # [7, 9, 1, 1, 4] -> [7, 9, 1, 1, 4, 7, 9, 1, 1, 4]
```

수열이 원형이라 끝과 처음이 이어진다 (`4 + 7` 같은 수열도 센다).
두 번 이어 붙이면 어느 시작점에서든 길이 `length` 까지는 **슬라이스 한 번**으로 잘린다. 나머지 연산(`%`)으로 인덱스를 돌릴 필요가 없다.

### 길이 1 은 따로, 길이 2 부터는 반복문으로

- `aset.update(elements)` 가 길이 1 짜리 합(원소 자체)을 넣는다
- `i` 는 `0` 부터 `length-2` 까지라 `i+2` 는 길이 2 부터 `length` 까지다
- 전체 길이의 합은 시작점마다 똑같이 나오지만 `set` 이라 한 번만 센다

`for k in range(1, length+1)` 로 길이를 직접 돌면 `update` 와 `+2` 보정 없이 한 덩어리가 된다. 결과는 같다.

### 걸린 시간

로컬에서 무작위 입력으로 잰 시간:

| 길이 | 통과한 코드 |
|---|---|
| 250 | 0.03s |
| 500 | 0.20s |
| 1,000 | 1.49s |

길이가 2배가 되면 약 7–8배 → **O(n³).** 시작점(n) × 길이(n) × `sum` 으로 더하는 개수(최대 n) 이다.
최대 길이가 1,000 이라 통과했지만, 2,000 이었다면 10초가 넘는 계산이다.

## 이렇게 했으면 어땠을까

### 1. 만약 길이를 늘리면서 합을 이어서 더한다면

```python
def solution(elements):
    n = len(elements)
    sums = set()
    for start in range(n):
        total = 0
        for k in range(n):
            total += elements[(start + k) % n]
            sums.add(total)
    return len(sums)
```

길이 3 의 합은 **길이 2 의 합 + 다음 원소 하나**다. 매번 `sum` 으로 처음부터 다시 더할 필요가 없다.
그러면 `sum` 한 번(최대 n번 더하기)이 덧셈 한 번이 되어 **O(n²).** 길이 1,000 에서 0.09s.

이 코드는 이어 붙이지 않고 `% n` 으로 돌았다. 어느 쪽이든 된다.

### 2. 만약 누적합을 미리 만들어 둔다면

```python
def solution(elements):
    n = len(elements)
    ext = elements * 2
    pre = [0]
    for x in ext:
        pre.append(pre[-1] + x)          # pre[i] = 앞에서부터 i개의 합
    return len({pre[s + k] - pre[s] for s in range(n) for k in range(1, n + 1)})
```

`pre[e] - pre[s]` 가 `s` 부터 `e-1` 까지의 합이다. 어떤 구간의 합이든 **빼기 한 번**으로 나온다.
이 문제는 1번으로 충분하지만, "구간 합을 여러 번 물어보는" 문제에서는 이 방식을 쓴다. 길이 1,000 에서 0.07s.

| 방식 | 구간 합 하나 | 전체 | 길이 1,000 |
|---|---|---|---|
| 통과한 코드 (`sum(슬라이스)`) | O(n) | O(n³) | 1.49s |
| 이어서 더하기 | O(1) | O(n²) | 0.09s |
| 누적합 | O(1) | O(n²) | 0.07s |

세 방식 모두 무작위 5,000건에서 결과가 같았다.

## 배운 것

1. **원형 배열은 두 번 이어 붙이면** 슬라이스로 다룰 수 있다. 아니면 인덱스에 `% n`
2. `sum(lst[a:b])` 는 한 줄이지만 **O(b - a)** 다. 반복문 안에서 쓰면 복잡도가 한 단계 올라간다
3. 길이가 1씩 늘어나는 구간의 합은 **앞의 합에 하나만 더한다.** 여러 구간을 아무렇게나 물어보면 누적합
4. "서로 다른 값의 개수" 는 `set` 에 넣고 `len`
