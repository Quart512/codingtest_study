## 풀이의 핵심

두 가지를 정하면 풀린다.

- **점이 아니라 길을 센다.** 길은 출발점과 도착점 두 좌표의 짝 `(now, next_step)` 이다
- **길에는 방향이 없다.** `(0,0) → (0,1)` 과 `(0,1) → (0,0)` 은 같은 길이다

통과한 코드는 길을 **한 방향으로만** 저장하고, 셀 때 **양쪽을 다** 확인한다.

```python
route = (now, next_step)
reverse_route = (next_step, now)
if route not in move_set and reverse_route not in move_set:
    answer += 1
move_set.add(route)
```

**그래서 `answer` 를 따로 세야 했다.** `move_set` 에는 같은 길이 방향만 다르게 두 번 들어갈 수 있다.
`"UD"` 를 걸으면 `((0,0),(0,1))` 과 `((0,1),(0,0))` 이 둘 다 들어가서, `len(move_set)` 은 2 지만 정답은 1 이다.

경계 검사는 공원 산책에서 배운 순서 그대로다. 다음 좌표를 먼저 계산해 보고, 안에 있을 때만 옮긴다. → [[공원산책]]

좌표를 리스트가 아니라 **튜플**로 둔 것도 맞다. `set` 에는 바뀌지 않는(해시 가능한) 값만 들어간다. 리스트를 넣으면 `TypeError: unhashable type: 'list'`. → [[해시]]

## 이렇게 했으면 어땠을까

### 1. 만약 길을 방향 없는 하나의 값으로 저장한다면

```python
def solution(dirs):
    D = {"U": (0, 1), "D": (0, -1), "R": (1, 0), "L": (-1, 0)}
    x, y = 0, 0
    roads = set()
    for d in dirs:
        dx, dy = D[d]
        nx, ny = x + dx, y + dy
        if not (-5 <= nx <= 5 and -5 <= ny <= 5):
            continue
        roads.add(frozenset([(x, y), (nx, ny)]))
        x, y = nx, ny
    return len(roads)
```

- `frozenset` 은 순서가 없는 바뀌지 않는 집합이다. `frozenset([A, B])` 와 `frozenset([B, A])` 가 **같은 값**이라 `set` 에 한 번만 들어간다
- 그러면 반대 방향을 따로 확인할 필요도, `answer` 를 따로 셀 필요도 없다. **`len(roads)` 가 곧 답**이다
- 방향 → 좌표 변화를 딕셔너리로 두면 `see_next` 의 `if` 네 갈래가 한 줄이 된다 (공원 산책 노트의 대안과 같은 방식)

### 2. 만약 양쪽 방향을 둘 다 넣는다면

```python
roads.add((now, nxt))
roads.add((nxt, now))
...
return len(roads) // 2
```

길 하나가 언제나 두 번씩 들어가므로 마지막에 2로 나눈다. 이것도 맞는다.

| 방식 | 저장 | 셀 때 | 답 |
|---|---|---|---|
| 통과한 코드 | 한 방향만 | 양쪽 다 확인하며 `answer += 1` | `answer` |
| `frozenset` | 방향 없는 값 하나 | 확인 필요 없음 | `len(roads)` |
| 양쪽 다 넣기 | 두 방향 모두 | 확인 필요 없음 | `len(roads) // 2` |

세 방식 모두 무작위 20,000건에서 결과가 같았다.

### 3. `dir` 은 파이썬 내장 함수 이름이다

`for dir in dirs:` 는 동작하지만, 그 함수 안에서는 내장 함수 `dir()` 을 못 쓰게 가려진다. `d` 나 `direction` 처럼 다른 이름이 안전하다.

## 배운 것

1. **무엇을 셀지 먼저 정한다.** 점인가 길인가, 길에 방향이 있는가
2. 방향 없는 짝은 `frozenset` 으로 하나의 값으로 만들 수 있다. 그러면 `len(set)` 이 곧 개수다
3. `set` 에 넣는 좌표는 튜플. 리스트는 해시가 안 된다
4. 격자 이동은 **옮기기 전에 검사**. 공원 산책과 같은 순서
