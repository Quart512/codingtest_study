# 교과서 (작성 예정)

코딩테스트에 필요한 **개념 자체**를 정리하는 곳. "이게 무엇이고 왜 이렇게 동작하는가".

다른 폴더에서 이미 위키링크로 걸어 두었기 때문에, 아래 이름 그대로 노트를 만들면 링크가 자동으로 연결된다.
(옵시디언 그래프 뷰에서 지금은 **속이 빈 회색 점**으로 보인다 = 아직 안 만든 노트)

## 만들 노트 목록

| 노트 이름 | 다뤄야 할 것 | 어디서 링크되어 있나 |
|---|---|---|
| `시간복잡도.md` | 빅오 표기가 무슨 뜻인지, O(1)/O(n)/O(n log n)/O(n²) 감각, n의 크기별 허용 복잡도 | 앞에서 빼야 할 때, 두 뭉치 순서대로 꺼내기, 카드뭉치 |
| `리스트.md` | 파이썬 list 의 내부 구조(연속된 배열), 각 연산의 비용, 슬라이싱 | 앞에서 빼야 할 때 |
| `deque.md` | 이중 연결 블록 구조, popleft/appendleft, BFS 큐로서의 용도 | 앞에서 빼야 할 때 |
| `연결 리스트.md` | 노드/포인터 개념, 단일·이중·원형, 배열과의 트레이드오프, 파이썬에서 직접 구현을 안 하는 이유 | 앞에서 빼야 할 때 |
| `투 포인터.md` | 인덱스 두 개로 훑는 패턴, 슬라이딩 윈도우와의 관계 | 두 뭉치 순서대로 꺼내기, IndexError |

## 작성 규칙

- 파일 이름 = 개념 이름. 링크가 이름으로 걸리므로 나중에 바꾸지 말 것 (바꿔야 하면 옵시디언에서 **파일명 변경**하면 링크가 따라온다)
- 맨 위에 frontmatter 로 `tags: [교과서, ...]`
- 맨 아래에 "이 개념을 언제 쓰는가" 링크 → `개념정리/` 노트로
- 코드 예시는 짧게. 긴 코드는 `코드/` 에 .py 로 두고 링크

## 폴더 간 역할 구분

- **교과서** = 개념이 *무엇*인가 (지식)
- **개념정리** = *언제* 그 개념을 쓰는가 (판단)
- **오답노트** = *어디서* 틀렸는가 (경험)
- **에러** = *왜* 터졌는가 (증상)
