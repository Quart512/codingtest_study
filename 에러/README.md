# 에러

**왜 터졌는가**를 에러 메시지에서 역추적하는 곳. 에러 타입 하나당 노트 하나.

파일 이름은 **에러 메시지 원문 그대로** 둔다. 다음에 같은 에러를 만났을 때 그 문장으로 검색해서 찾을 수 있어야 한다.

## 원칙

- 특정 문제 전용이 아니라 **에러 타입 전체**를 다룬다. 같은 에러를 또 만나면 사례를 아래에 덧붙인다
- 원인을 흔한 순서대로 나열한다
- 마지막에 **예방 습관**. 이게 다음 번에 안 틀리게 해주는 부분이다
